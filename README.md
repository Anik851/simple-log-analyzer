# Simple Log Analyzer

## Description
A Python-based log analysis tool that scans system log files to detect failed login attempts and successful logins.

## Features
- Counts failed login attempts
- Counts successful logins
- Detects potential brute-force attack patterns
- Error handling for missing files

## Technologies Used
- Python
- File Handling
- Conditional Logic

## How to Run

```bash
python log_analyzer.py
